### Libasm  
The Libasm is a project designed to deepen your understanding of assembly language. It involves re-implementing some basic functions of the C standard library in x86-64 assembly. This project is a great opportunity to explore low-level programming, optimize performance, and develop a deeper understanding of how functions operate at the machine level.

For more information, please refer to the subject in the git.

### Compilation  
**Mandatory part**  
Use the following command to compile and execute the binary:
```bash
  make
  ```
